# Settings

| Screen | Use it to |
| --- | --- |
| [Company data](company/) | Business name, address, contacts, tax details, logos, favicon, social links, apps and payment icons |
| [General settings](general/) | Storefront access, appearance, catalog, checkout, inventory, coupons, taxes, emails, storefront colours and AI |
| [Search](search/) | Product search health, index building and search settings |
| [Languages and translations](languages/) | Active languages, the default language and your own wording of the interface |
| [Currencies](currencies/) | The primary currency, secondary currencies, exchange rates and number formats |

Company data and General settings need the *Manage general and company settings* permission.
