# Product packages

**Catalog → Products → Product packages** (`/admin/product-packages`)

A **product package** is a reusable set of accessories that you create once and offer on many products, for example
*iPhone accessories* (case, charger, cable) on every iPhone. Customers can add the whole set to their cart from the
product page.

## Creating a package

1. Click **New package** and enter the **Package name** in each language.
2. Under **Package contents**, search by product name or SKU and press Enter (up to 20 results), then **Add** the
   accessories you want, up to **30** products in order. The product the package is shown on is included automatically.
3. Save.

## Assigning a package

Save the package first, then open **Assignments**:

- **Choose products**: tick the products that should offer this package;
- **Choose a category**: applies the package to the products currently placed directly in that category.

Each product can have **one** package: applying a package replaces any previous assignment. You can also choose a
package for a single product in its editor, in the **Frequently bought together** tab (**Choose a package**).

## Adding to the cart

When a customer adds the package, every item is checked (stock, quantity rules, visibility). If one item cannot be
added, nothing is added.

## Deleting

Deleting a package removes it and its assignments. Products and their manually chosen *Frequently bought together* items
stay intact. A product that is part of a package must be removed from it before the product can be permanently deleted.

## Permissions

*View products* to see packages, *Update products* to change them.
