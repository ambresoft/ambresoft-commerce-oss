# Catalog

The **Catalog** menu holds everything you sell and how it is organized.

| Screen | Menu | Use it to |
| --- | --- | --- |
| [Products](products/) | Catalog → Products → Products | Create and edit products: names, prices, stock, images, SEO, shipping and more |
| [Features](features/) | Catalog → Products → Features | Define product characteristics (colour, size, storage…) used for specifications, filters, comparison and variations |
| [Variation groups](variation-groups/) | Catalog → Products → Variation Groups | Link products that are versions of each other (for example the same phone in three colours) |
| [Availability statuses](availability-statuses/) | Catalog → Products → Availability statuses | The labels customers see, such as *Immediately available* or *Pre-order* |
| [Product packages](product-packages/) | Catalog → Products → Product packages | Sets of products offered together, with an "add all to cart" action |
| [Categories](categories/) | Catalog → Categories | The category tree of your store |
| [Brands](brands/) | Catalog → Brands | Brands with logos, descriptions, banners and their own pages |
| [Reviews](reviews/) | Catalog → Reviews | Approve, reject or correct customer reviews |
| [Carts](carts/) | Catalog → Carts | See what visitors and customers have in their carts |

## Recommended order for a new store

1. Create your **categories** (or import them from CSV).
2. Create your **features** (for example *Colour*, *Storage*, *Material*) and choose which categories they apply to.
3. Create your **brands**.
4. Create your **products**, assign a category, brand and feature values, add images and prices.
5. Group product versions into **variation groups** if you sell the same item in several colours or sizes.
6. Check **availability statuses** and adjust their wording.

For large catalogs, use [Imports / Exports](../system/imports-exports/) to load categories, brands and products from
CSV files.
