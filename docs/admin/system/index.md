# System

These menu entries keep the store running:

| Menu | Use it to |
| --- | --- |
| [Add-ons](addons/) | Install, enable, configure and upgrade extensions |
| [Cache](cache/) | Switch the storefront content cache on and clear it |
| [Logs](logs/) | Review the audit log of every change and the AI log |
| [Imports / Exports](imports-exports/) | Load and download products, categories, brands and regions as CSV files |
