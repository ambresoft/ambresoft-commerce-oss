# Website

The **Website** menu controls what the storefront looks like and its content pages.

| Screen | Use it to |
| --- | --- |
| [Layouts](layouts/) | Design every storefront page with grids and blocks: header, footer, homepage, category, product, cart, checkout… |
| [Menus](menus/) | Header, footer and other navigation menus |
| [Pages](pages/) | Content pages such as *About us*, *Privacy policy* or *Returns* |
| [FAQs](faqs/) | Reusable questions and answers for products, categories and pages |
| [SEO Rules](seo-rules/) | Redirect old addresses to new ones |
| [Social login](social-login/) | Let customers sign in with Google |
| [Code editor](code-editor/) | Edit the storefront theme's source files (for developers) |

When the **Sitemap** add-on is enabled, an **XML Sitemap** entry is added here too (see
[Bundled add-ons](../../bundled-addons/sitemap/)).
