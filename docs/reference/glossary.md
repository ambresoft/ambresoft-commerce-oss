# Glossary

**Add-on**
: An optional extension (payment method, search engine, analytics…) installed in **Add-ons**. Bundled add-ons ship with
  the platform; others are uploaded as ZIP files. Installed add-ons start disabled.

**Additional categories**
: Extra categories a product is also listed in, besides its main category.

**Audit log**
: The record of who changed what and when in the administration (**Logs → Audit Logs**).

**Availability status**
: A customer-facing label such as *Immediately available* or *Pre-order*. Text only; it does not change stock.

**Block**
: One piece of a storefront page (banner carousel, product carousel, menu, HTML…) placed in a grid of a layout.

**Brand**
: The maker of a product. Each active brand has its own page, for example `/apple`.

**Bundled add-on**
: An add-on shipped in the platform's `modules/` folder, for example Stripe Checkout or Typesense search.

**Combination**
: In a variation group, the set of option values that identifies one version (for example *Black + 256 GB*). It must be
  unique within the group.

**Customer group**
: A segment of customers (*Retail*, *VIP*…) used to restrict visibility, target sale prices and promotions, and limit
  shipping methods.

**Customer profile**
: A customer's record (name, email, phone, addresses, groups). It can be linked to an online account.

**Default language**
: The main store language. Required content (for example a product's name) is entered in it, and it is used when a
  translation is missing.

**Defining feature**
: A feature that distinguishes the products of a variation group, for example *Colour*.

**Draft (product)**
: A product saved before it is complete. It cannot be activated until it has a name, SKU, price and category.

**Feature**
: A product characteristic such as *Colour*, *Storage* or *Waterproof*: text, single choice, multiple choices, number or
  yes/no. Shown in specifications and usable as a filter.

**Feature purpose**
: What a feature is used for: *Standard Attribute*, *Brand / Author Landing Pages* or *Variations as separate products*.

**Final status**
: An order status that ends an order (Completed, Cancelled, Failed). Editing such an order asks for confirmation.

**Gift card**
: A prepaid card with a balance, used to **pay** for orders. Not a discount.

**Grid**
: A rectangular area of a layout on the 16-column system, holding blocks or smaller grids.

**Initial status**
: The order status new orders start in (*Open* by default).

**Landing page (category)**
: A category that shows its subcategories as cards instead of products.

**Layout**
: The design of one kind of storefront page (homepage, category, product, cart…), built from grids and blocks in
  **Website → Layouts**. The **Default** layout holds the shared header, navigation and footer.

**Leaf category**
: A category without subcategories. Products are placed in leaf categories.

**Main category**
: The category that sets a product's address and breadcrumb.

**Option**
: A predefined value of a choice feature, for example *Black* for *Colour*.

**Order status**
: The step an order is in (Open, Processing, Ready for shipment, Shipped, Completed…). Each status sets the stock
  movement and the customer email.

**Order summary**
: The printable, invoice-style document of an order, emailed when the order reaches a status that sends it. Not an
  official fiscal invoice.

**Payment status**
: Whether an order is *Not paid*, *Payment pending*, *Partially paid* or *Paid*, calculated from the payments received.
  Separate from the order status.

**Permission**
: The right to see or do something in the administration, for example *Update products*. Permissions are grouped into
  roles.

**Primary currency**
: The currency all prices are entered and stored in.

**Promotion**
: An automatic discount or free shipping applied when an order meets conditions, without a code.

**Rate area**
: A group of countries or regions, used to choose tax rates and shipping rates.

**Role**
: A named set of permissions given to staff users (Super Admin, Store Admin, Catalog Manager…).

**Sale (product)**
: A scheduled lower price on a product, set in the product's **Sale** tab.

**Scheduler**
: The background service that runs regular tasks (search indexing, newsletters, cleanups) every few seconds or minutes.

**SKU**
: Stock keeping unit: your own unique product code.

**Slug / SEO name**
: The part of a page address that you choose, for example `smartphones` in `/phones/smartphones`.

**Sticker**
: A badge shown on product pictures, such as *New* or *-20%*. Manual or dynamic.

**Storefront**
: The public shop your customers use.

**Super Admin**
: The role with every permission. At least one active Super Admin always exists.

**Trash**
: Where deleted products go first. They can be restored or permanently deleted from there.

**Variation group**
: A set of separate products that are versions of the same item (colours, sizes), shown with selectors on the product
  page.

**Worker**
: The background service that processes queued jobs (search indexing, newsletters, file cleanup).
