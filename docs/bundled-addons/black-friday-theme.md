# Black Friday Theme

Switches the storefront to a **charcoal palette with gold accents** for Black Friday and similar campaigns.

## Using it

- **Add-ons → Black Friday Theme → Install → Enable**: the dark palette appears on the next page load.
- **Disable** to return to your saved storefront colours.

It changes **colours only**: headers, menus, product views, cart, checkout, account pages and dialogs. Layouts, content,
product images, swatches, stickers and your banner designs keep their own colours, and nothing you saved is changed. The
administration is not affected. There are no settings and no scheduling: enable and disable it yourself.

{: .note }
> If you added your own theme code in the [Code editor](../../admin/website/code-editor/), it may need its own dark
> colours.
