# Getting started

This section takes you from an empty computer to a running store.

1. Check the [requirements](requirements/).
2. [Install Ambresoft Commerce](installation/) on your computer with Docker, optionally with a complete demo store.
3. [Set up your store](first-steps/): company details, languages, currencies, taxes, shipping, payments and your
   catalog, in the order that works best.
4. Learn the vocabulary in [key concepts](concepts/) so the rest of the documentation makes sense.
5. When a new version is released, follow [upgrading](upgrading/).
6. Before real customers arrive, read [going to production](production/).

{: .note }
> The Docker setup in the repository is a **local development environment**. It is the quickest way to try the
> platform and to build your store, but it is not a hardened production server. See
> [going to production](production/) before you publish a store to customers.
